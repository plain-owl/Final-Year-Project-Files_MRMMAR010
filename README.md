# Final-Year-Project-Files_MRMMAR010
MATLAB code and Excel dataset file for MEC4128Z Project 

Nine live scripts are included in this folder. 

The stress level fitting live scripts are described below: 
1. StressLevelFitting_2P_Lognormal: For fitting the 2-Parameter Lognormal distribution, to the data at each stress level of the dataset. Both Maximum Likelihood Estimation and Probability Plotting and Linear Rectification are used to estimate the parameters, with PPLR acting as a validatory and visual tool. The script also contains the code to save results and load them into a separate results script. See below. 
2. StressLevelFitting_2P_Weibull: For fitting the 2-Parameter Weibull distribution, to the data at each stress level of the dataset. Both Maximum Likelihood Estimation and Probability Plotting and Linear Rectification are used to estimate the parameters, with PPLR acting as a validatory and visual tool. The script also contains the code to save results and load them into a separate results script. See below. 
3. StressLevelFitting_3P_Weibull: For fitting the 3-Parameter Weibull distribution, to the data at each stress level of the dataset. Both Maximum Likelihood Estimation and Probability Plotting and Linear Rectification are used to estimate the parameters, with PPLR acting as a validatory and visual tool. For the 3-Parameter Weibull, the parameter estimation techniques are adjusted to account for the location parameter. However, the MLE does not produce reliable estimates for the dataset provided in this folder due to the shape parameter being below unity. The script also contains the code to save results and load them into a separate results script. See below. 
4. StressLevelFitting_Gumbel: For fitting the 2-Parameter Lognormal distribution, to the data at each stress level of the dataset. Both Maximum Likelihood Estimation and Probability Plotting and Linear Rectification are used to estimate the parameters, with PPLR acting as a validatory and visual tool. The script also contains the code to save results and load them into a separate results script. See below. 

5. GlobalResidualModel: For generating the P-S-N curves for the 2P Lognormal and 2P Weibull fatigue life models. The median S-N curve was located for the dataset, and the observations pooled across all stress levels as their residuals. The Normal and Minimum Extreme Value distributions were fitted to the residuals, corresponding to the 2P Lognormal and 2P Weibull fatigue life models respectively.
6. MonteCarloSimulation: For running a MCS for the 2P Lognormal and 2P Weibull distribution scenarios. The load uncertainty and material scatter were propagated using this simulation. Histograms and the S-N diagrams were the visual outputs of this script.
7. SobolSensitivityAnalysis: For generating the first and total order Sobol indices. The 2P Weibull and 2P Lognormal distributions were the distributions investigated, and load uncertainty and material scatter were the inputs being investigated for their effect on the variance of the output - fatigue life.
8. SampleSizeInvestigation: Script with bootstrap method to investigate the parameter estimation and B1 life prediction behaviour with increasing sample size.
